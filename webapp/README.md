# Дитячий розклад (webapp)

Невеликий **статичний застосонок** для ведення розкладу дітей і синхронизізації
між телефоном і ноутбуком. Розміщується на **GitHub Pages** — без сервера і без бази даних.

## Що вміє

- Декілька дітей, у кожної — свій колір і клас.
- **Розклад на тиждень**: сітка «час уроків × дні». Натиснувши на кліточку, вписуєте предмет і кабінет/вчителя.
- Часі уроків редактуються в форматі `номер|початок-кінец` (наприклад `1|08:00-08:45`).
- Списки **домашніх завдання** і **контрольних/екзаменів**.
- Експорт/імпорт JSON (бэкап, перенос).
- Синхронизація через **secret GitHub Gist** — телефон і ноутбук читають і пишут в один файл.

Файли: `webapp/index.html`, `webapp/style.css`, `webapp/app.js`.

## Запуск на GitHub Pages

1. Заванжи на GitHub код цього репозиторию.
2. GitHub → **Settings → Pages → Source: GitHub Actions**.
3. Воркфлоу `.github/workflows/pages.yml` автоматично задеплоить папку `webapp/`.
4. Застосонок буде доступний за адресою:
   `https://<ваш-логін>.github.io/<назва-репо>/`

Для локальной перевірки і без публікації просто відкрийте `webapp/index.html` в браузері.

## Синхронизація миж пристроями (Gist)

За замовчанні дані лежать только в localStorage браузера (локально). Щоб телефон і
ноутбук бачили те ж дані:

1. У GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate**.
   Вкажите назву і область `gist`, далі Permissions → Gist → Access: **Read and write**. Скопійте токен `github_pat_…`.
2. Зробіте **secret gist** (New gist → Secret), файл назвіте как завготь — застосонок перепише його как `schedule.json`.
   Скопійте **Gist ID** (це частина адреса, що виглядить як `1a2b3c4d5e6f7g8h`).
3. У застосонку: меню **☰** → **Налаштування Gist** → впишить Gist ID і токен → **Зберегти**.
   Тепер після кожної зміни застосонок пише в Gist, а запущений на інше пристрої читає з него.

> Токен лежить тільки в вашому браузері (localStorage) і відправляться виключно на
> `api.github.com`. Для більшої безпечності можете зробить собі окремно налащ colaboraciu — дивиться док. GitHub.

## Обмеження

- Дані в Gist — **secret** (не публічный), але токен у браузері дозволяє читать/писуть.
  Це нормально для особистого застосонку, не для публічного.
- Синхронизація — «хто останний затерав» (last-write-wins), без merge-конфликтів між пристроями.
