# Changelog

Усі важливі зміни в цьому проєкті документуються в цьому файлі.

Формат заснований на [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/),
а версії — на [Semantic Versioning](https://semver.org/lang/uk/).

> **Статус релізів.** Тегів версій у репозиторії ще немає. Історія нижче згрупована
> за датами комітів гілки `main`; перший публічний реліз позначено `0.1.0`.

## [Unreleased]

### Added
- `README.md` — повна документація проєкту: можливості, запуск локально, розгортання
  на GitHub Pages, налаштування синхронізації через Gist, модель даних, вимоги до
  браузерів, відомі обмеження.
- `CHANGELOG.md` — журнал змін за форматом Keep a Changelog.

### Known issues
- Домашні завдання та контрольні можна лише редагувати, але **не видаляти** —
  у списках немає кнопки видалення. Обхідний шлях: експорт JSON → правка файлу →
  імпорт.
- Переміщення карток drag & drop не працює на сенсорних екранах
  (HTML5 Drag and Drop не підтримується на touch-пристроях). На телефоні
  користуйтеся редактором уроку.
- `.github/workflows/validate.yaml` запускає **HACS validation** — перевірку для
  Home Assistant custom components. Для цього статичного вебзастосунку вона
  не застосовна й не перевіряє нічого корисного.
- У коді є невикористовувані функції: `todayKey()` та `tint()`.

## [0.1.0] — 2026-09-25

Перший повний публічний реліз. Усі зміни нижче відповідають гілці `main`
(коміти `3a34f7b`…`1fd3c49`).

### Added
- Статичний застосунок «Дитячий розклад» (`index.html` + `style.css` + `app.js`)
  без збірки та залежностей, з темною темою на CSS-змінних.
- Початкове налаштування проєкту: `.gitignore`, ліцензія MIT
  (`dc2d7b7`, `3a34f7b`).
- CI-workflow `.github/workflows/validate.yaml` із запусками на `push`,
  `pull_request`, щоденним розкладом і ручним запуском
  (`8d7af93`).
- Публікація застосунку з кореня репозиторію для GitHub Pages
  (`0e1cb14`).
- Базовий застосунок розкладу з підтримкою кількох дітей, вкладок, редагування
  уроків, домашніх завдань і контрольних, збереження в `localStorage`
  (`dc2d7b7`).
- Синхронізація між пристроями через secret Gist (`schedule.json`),
  індикатор стану синхронізації, налаштування токена й Gist ID
  (`dc2d7b7`).
- Експорт та імпорт даних у форматі JSON (`dc2d7b7`).
- Прив'язка кольору до предмета з успадкуванням на всі картки тижня
  та drag & drop для переміщення карток уроків
  (`c971a04`).
- Структурований редактор розкладу: «Розклад дзвінків» (8 уроків + 2 додаткові
  заняття) і перехід до табличної сітки 7 × 10
  (`9e97313`).
- Міграція старих даних: кольори, збережені в картці уроку, переносяться
  в `subjectColors` через `migrateSubjectColors()` (`c971a04`, `9e97313`).

### Changed
- Розклад переведено на регулярну тижневу сітку з редагуванням дзвінків
  замість довільного списку занять (`9e97313`).
- Покращено переклади українською мовою в усьому інтерфейсі (`84c6fab`).
- Файл `app.js` винесено в окремий зовнішній скрипт замість інлайн-коду
  (`1fd3c49`).

### Fixed
- Елементи з атрибутом `hidden` більше не відображалися — додано примусове
  правило `[hidden]{display:none !important}` (`d6003e4`).
- Виправлено відсутність кольорів у картках уроків, зокрема для даних,
  створених до впровадження спадковості кольору (`c971a04`).

### Removed
- Workflow деплою GitHub Pages видалено під час прибирання проєкту —
  публікацію виконуйте через **Settings → Pages** (`1fd3c49`).

## Про історію проєкту

Репозиторій раніше містив **Family School Cards** — набір Lovelace-карток для
Home Assistant (`family-timetable-card`, `family-overview-card`,
`family-homework-card`, `family-exam-card`), який читав розклад із WebUntis.
У ньому були власні `README.md` (606 рядків, німецькою) і `CHANGELOG.md`
(217 рядків, до версії 1.5.0), `hacs.json`, файл `family-school-cards.js`
(2310 рядків) і тест `tests/timetable.test.cjs`.

Коміт `1fd3c49` («clean the project») видалив усе це, залишивши лише
статичний вебзастосунок. Старі `README.md` і `CHANGELOG.md` **не відновлено**:
вони описували інший продукт, іншу мову й інший спосіб встановлення.
Натомість документацію написано українською відповідно до поточного
застосунку.

Перелік видалених файлів — у коміті:
`git show --stat 1fd3c49`.
