## [0.3.0] — 2026-XX-XX

Перехід на Cloudflare Pages + KV. Прибрано ручний цикл «експорт → пуш → чекати деплой» — тепер редагування зберігається одним кліком через API.

### Added
- **Cloudflare Pages Function** `functions/api/schedule.js`:
  - `GET /api/schedule` — публічне читання розкладу з KV (без пароля).
  - `PUT /api/schedule` — запис у KV з перевіркою заголовка `X-Edit-Password`.
  - CORS, `no-store` для завжди свіжих даних, поле `updatedAt` при збереженні.
- **Режим редагування** з простою парольною авторизацією:
  - Модалка «Режим редагування» → введення пароля → перевірка через тестовий PUT.
  - Пароль зберігається як Cloudflare **Secret** (`EDIT_PASSWORD`).
  - Локально пароль зберігається в `localStorage` (`fsc.password.v1`).
- **Кнопка «💾 Зберегти на сервер»** у футері — з'являється в режимі редагування, пульсує помаранчевим, коли є незбережені зміни.
- **Банер «Режим перегляду»** зверху для незалогінених відвідувачів із кнопкою «Увійти для редагування».
- **Індикатор стану** розширено:
  - 🟢 синхронізовано (з датою останнього оновлення);
  - 🔵 локальні зміни (пульсує);
  - 🟡 триває збереження;
  - 🔴 помилка;
  - ⚪ режим перегляду.
- **Тости** про успіх/помилку операцій (замість `alert()`).
- **Ctrl+S / Cmd+S** — швидке збереження на сервер.
- **Попередження `beforeunload`** при закритті вкладки з незбереженими змінами.
- Оновлення (`fsc.updatedAt.v1`) відображається в підказці індикатора.
- Кнопки «×» для видалення дитини та кнопка «Видалити» в редакторі домашки/контрольних — приховуються в режимі перегляду.
- Файли для локальної розробки: `wrangler.toml`, `package.json`, `.dev.vars.example`.

### Changed
- Джерело даних: замість файлу `schedule.json` у репозиторії — Cloudflare KV.
- UI-контроли редагування (кнопки, DnD, чекбокси, кліки по клітинках, «+ Додати» для домашки/контрольних) вимикаються, коли пароль не введено.
- Уся логіка редагування захищена викликами `canEdit()`.
- Експорт/імпорт JSON залишились як резервний механізм (доступні і без пароля для експорту).
- README повністю переписано під нову архітектуру + додано покрокову інструкцію налаштування Cloudflare (5 кроків).

### Removed
- Service Worker (`sw.js`) — не потрібен, Cloudflare сам робить кешування та швидку доставку статики.
- Файл `schedule.json` у корені репозиторію — дані живуть у KV.
- Модалка «Як опублікувати зміни» — тепер зайва.
- Кнопка «Оновити з сервера» лишилась (для форс-синхронізації), але вже не критична.

## [0.2.0] — 2026-XX-XX

Спрощення архітектури: прибрано синхронізацію через GitHub Gist, замість неї — публічний файл `schedule.json` у репозиторії та Service Worker.

### Added
- `sw.js` — Service Worker для офлайн-режиму та сповіщення про нову версію.
- Читання розкладу з файлу `schedule.json` поруч із застосунком (без токенів).
- Кнопка «Оновити з сервера» — перезаписує локальні дані серверною версією.
- Кнопка «Видалити» в редакторі домашки/контрольних.
- Модальне вікно з інструкцією після експорту.
- Індикатор стану у топбарі: 🟢/🔵/🟡/🔴.
- Ключ `fsc.dirty.v1` у `localStorage` — маркер локальних змін.

### Changed
- Локальні зміни більше не перетираються серверною версією при завантаженні.
- Ім'я файлу експорту змінено з `family-schedule.json` на `schedule.json`.
- Оновлено README: розділ «Публікація змін», опис Service Worker.

### Removed
- Синхронізація через secret Gist (`POST/PATCH /gists`).
- Модалка «Налаштування Gist», ключ `fsc.settings.v1`.
- Функції `gistFetch()`, `gistPush()`, `saveSettings()`, `syncIndicator()`.
- Мертвий код: `todayKey()`, `tint()`.
- Константи `DAY_SHORT`, `LS_SETTINGS`, `GIST_FILENAME`, `GIST_API`.

### Fixed
- Правописні помилки в українському тексті: «синхронизацію» → «синхронізацію», «пристройці» → «пристрої», «миж» → «між».
- Уніфіковано розділювачі в списках: `—` і `•` замість `-` і `.`.

## [0.1.0] — 2026-09-25

Перший повний публічний реліз.

### Added
- Статичний застосунок «Дитячий розклад» (`index.html` + `style.css` + `app.js`)
  без збірки та залежностей, з темною темою на CSS-змінних.
- Кілька дітей, вкладки, редагування уроків, домашка, контрольні.
- Збереження в `localStorage`.
- Синхронізація через secret Gist. *(У 0.2.0 замінено на публічний файл + SW, у 0.3.0 — на Cloudflare Pages + KV.)*
- Експорт та імпорт JSON.
- Прив'язка кольору до предмета, drag & drop карток.
- Редактор «Розклад дзвінків» (8 уроків + 2 додаткові заняття), таблиця 7 × 10.
- Міграція старих даних.

### Fixed
- `[hidden]{display:none !important}`.
- Кольори карток уроків для старих даних.

## Про історію проєкту

Репозиторій еволюціонував у три етапи:

1. **v0.1** — розклад як статична сторінка з опційною синхронізацією через GitHub Gist (потрібен був токен).
2. **v0.2** — Gist прибрано; дані читаються з `schedule.json` у самому репозиторії, редагування — ручним пушем.
3. **v0.3** — перехід на Cloudflare Pages + KV: редагування прямо з браузера, без git-циклу, з парольною авторизацією.
