## [0.2.0] — 2026-XX-XX

Спрощення архітектури: прибрано синхронізацію через GitHub Gist, замість неї — публічний файл `schedule.json` у репозиторії та Service Worker.

### Added
- `sw.js` — Service Worker для офлайн-режиму та сповіщення користувачів
  про нову версію розкладу.
- Читання розкладу з файлу `schedule.json` поруч із застосунком
  (без токенів, публічно).
- Кнопка **«Оновити з сервера»** — перезаписує локальні дані серверною версією.
- Кнопка **«Видалити»** в редакторі домашніх завдань і контрольних —
  видалення записів безповоротно.
- Модальне вікно з інструкцією після експорту («Як опублікувати зміни»).
- Тост-повідомлення «Доступна нова версія розкладу» з кнопкою «Оновити»
  при появі нової версії Service Worker.
- Індикатор стану у верхній панелі:
  - 🟢 зелений — дані з сервера,
  - 🔵 синій — є локальні зміни,
  - 🟡 жовтий — завантаження,
  - 🔴 червоний — помилка.
- Ключ `fsc.dirty.v1` у `localStorage` — маркер локальних змін,
  що ще не опубліковано.

### Changed
- Локальні зміни більше не перетираються серверною версією при завантаженні,
  якщо є маркер `fsc.dirty.v1`.
- Ім'я файлу експорту змінено з `family-schedule.json` на `schedule.json` —
  щоб його одразу можна було покласти в репозиторій.
- Оновлено README: розділ «Публікація змін» замість «Синхронізація через Gist»,
  описано роботу Service Worker і робочий цикл редагування.

### Removed
- Синхронізація через secret Gist (`POST/PATCH /gists`).
- Модальне вікно «Налаштування Gist» і кнопка «Налаштування Gist»
  в бічному меню.
- Ключ `fsc.settings.v1` у `localStorage`, поля `settings.token`,
  `settings.gistId` у стані.
- Функції `gistFetch()`, `gistPush()`, `saveSettings()`, `openSettings()`,
  `syncIndicator()`.
- Мертвий код: `todayKey()`, `tint()`.
- Константи `DAY_SHORT`, `LS_SETTINGS`, `GIST_FILENAME`, `GIST_API`
  (не використовуються після видалення Gist-логіки).

### Fixed
- Правописні помилки в українському тексті: «синхронизацію» → «синхронізацію»,
  «пристройці» → «пристрої», «миж» → «між».
- Уніфіковано розділювачі в списках домашки/контрольних: `—` і `•`
  замість `-` і `.`.

## [0.1.0] — 2026-09-25

Перший повний публічний реліз. Усі зміни нижче відповідають гілці `main` (коміти `3a34f7b`…`1fd3c49`).

### Added
- Статичний застосунок «Дитячий розклад» (`index.html` + `style.css` + `app.js`)
  без збірки та залежностей, з темною темою на CSS-змінних.
- Початкове налаштування проєкту: `.gitignore`, ліцензія MIT
  (`dc2d7b7`, `3a34f7b`).
- Публікація застосунку з кореня репозиторію для GitHub Pages
  (`0e1cb14`).
- Базовий застосунок розкладу з підтримкою кількох дітей, вкладок, редагування
  уроків, домашніх завдань і контрольних, збереження в `localStorage`
  (`dc2d7b7`).
- Синхронізація між пристроями через secret Gist (`schedule.json`),
  індикатор стану синхронізації, налаштування токена й Gist ID
  (`dc2d7b7`). *(У версії 0.2.0 замінено на публічний файл + Service Worker.)*
- Експорт та імпорт даних у форматі JSON (`dc2d7b7`).
- Прив'язка кольору до предмета з успадкуванням на всі картки тижня
  та drag & drop для переміщення карток уроків
  (`c971a04`).
- Структурований редактор розкладу: «Розклад дзвінків» (8 уроків + 2 додаткові
  заняття) і перехід до табличної сітки 7 × 10
  (`9e97313`).
- Міграція старих даних: кольори, збережені в картці уроку, переносяться
  в `subjectColors` (`c971a04`, `9e97313`).

### Changed
- Розклад переведено на регулярну тижневу сітку з редагуванням дзвінків
  замість довільного списку занять (`9e97313`).
- Покращено переклади українською мовою в усьому інтерфейсі (`84c6fab`).
- Файл `app.js` винесено в окремий зовнішній скрипт замість інлайн-коду
  (`1fd3c49`).

### Fixed
- Елементи з атрибутом `hidden` більше не відображалися — додано примусове
  правило `[hidden]{display:none !important}` (`d6003e4`).
- Виправлено відсутність кольорів у картках уроків, зокрема для даних,
  створених до впровадження спадковості кольору (`c971a04`).

### Removed
- Workflow деплою GitHub Pages видалено під час прибирання проєкту —
  публікацію виконуйте через **Settings → Pages** (`1fd3c49`).

## Про історію проєкту

Репозиторій раніше містив **Family School Cards** — набір Lovelace-карток для Home Assistant (`family-timetable-card`, `family-overview-card`, `family-homework-card`, `family-exam-card`), який читав розклад із WebUntis. Коміт `1fd3c49` («clean the project») видалив усе це, залишивши лише статичний вебзастосунок.

У версії **0.2.0** із застосунку прибрано й другу «спадщину» — синхронізацію через GitHub Gist із персональним токеном. Замість неї використовується публічний файл `schedule.json` у самому репозиторії GitHub Pages та Service Worker для сповіщень про оновлення.
