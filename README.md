# Дитячий розклад · Family School Web

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Статичний вебзастосунок для ведення шкільного розкладу, домашніх завдань і контрольних для кількох дітей. Не потребує бекенда, бази даних чи збірки: усі дані зберігаються у браузері, а за потреби синхронізуються між пристроями через закритий (**secret**) Gist на GitHub.

Інтерфейс — українською мовою, тема — темна, макет адаптований під телефон і планшет.

## Можливості

**Розклад**
- Тижнева таблиця 7 × 10: 8 уроків + 2 додаткові заняття (гуртки, тренування).
- Редактор «Розклад дзвінків»: час початку й кінця кожного уроку, назва та час для додаткових занять.
- Картки уроків із назвою предмета та вчителем/кабінетом.
- Переміщення карток drag & drop між будь-якими днями та рядками (обмін місцями, якщо ціль зайнята).

**Кольори предметів**
- Палітра з 12 кольорів + довільний колір через `<input type="color">`.
- Колір прив'язаний до **предмета**, а не до окремої клітинки: змінили колір «Математика» — оновилися всі картки математики за тиждень.
- Автодоповнення з уже використаних предметів (`<datalist>`).

**Діти**
- Кілька дітей, вкладки з кольоровим маркером, швидке перемикання.
- Для кожної дитини окремо: ім'я, клас, колір вкладки, власний розклад дзвінків, розклад, домашка й контрольні.

**Завдання й контрольні**
- Домашні завдання: предмет, опис, дата, клас/нотатка, чекбокс виконаного.
- Контрольні та іспити: предмет, опис, дата, кабінет.

**Дані**
- Збереження в `localStorage` браузера.
- Синхронізація через secret Gist (файл `schedule.json`).
- Експорт та імпорт JSON-файлу.
- Індикатор стану синхронізації у верхній панелі: сірий (вимкнено), зелений (активна), жовтий (триває), червоний (помилка).

## Швидкий старт

Проєкт не потребує встановлення залежностей чи збірки — це три статичні файли.

**Варіант 1 — просто відкрити файл**

Відкрийте `index.html` подвійним кліком. Усе працює, але деякі браузери обмежують
`localStorage` для локальних файлів, а GitHub API не любить запити зі схеми `file://`.

**Варіант 2 — локальний вебсервер (рекомендовано)**

```bash
# Python 3
python -m http.server 8000

# або Node.js
npx serve .
```

Далі відкрийте <http://localhost:8000>.

## Як користуватися

1. Натисніть **＋** у верхній панелі (або «Додати дитину» у бічному меню ☰) —
   вкажіть ім'я, клас і колір вкладки.
2. Натисніть **«Розклад дзвінків»** — задайте час початку/кінця для 8 уроків і
   назви та час для 2 додаткових занять.
3. Натискайте на порожні комірки («+ Додати урок») і заповнюйте предмет,
   вчителя/кабінет та колір.
4. Додавайте домашні завдання (**+ Домашка**) і контрольні (**+ Контрольна**).
5. За бажанням увімкніть синхронізацію через Gist, щоб бачити дані на інших пристроях.

> **Порада.** Якщо назва предмета вже існувала, редактор автоматично підставить
> її колір. Щоб задати колір усьому предмету — виберіть його на будь-якій картці
   й збережіть: усі картки з цією назвою стануть того самого кольору.

## Синхронізація через Gist

Дані зберігаються у **приватному (secret) Gist** на GitHub. Усі пристрої читають і
записують той самий файл `schedule.json`, тому розклад синхронізується.

### Крок 1. Отримайте токен

Створіть Personal Access Token із scope **`gist`**:

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens** →
   **Tokens (classic)** → **Generate new token (classic)**.
2. Увімкніть лише галочку **`gist`**, задайте термін дії.
3. Скопіюйте токен (він показується один раз).

> Для fine-grained токена потрібен дозвіл **Gists: Read and write**.

### Крок 2. Підключіть Gist у застосунку

Меню ☰ → **«Налаштування Gist»**:

| Поле | Що вписати |
|------|------------|
| **Gist ID** | залиште порожнім, щоб створити новий Gist автоматично, або вставте ID наявного |
| **GitHub token** | токен зі scope `gist` |

Натисніть **«Зберегти»**.

- Якщо **Gist ID порожній** — застосунок створить новий secret Gist через
  `POST /gists` і сам збереже його ID.
- Якщо **Gist ID вказано** — дані оновлюватимуться через `PATCH /gists/{id}`.

### Крок 3. Перенесіть на інший пристрій

На новому пристрої впишіть **той самий Gist ID** і токен — і дані завантажаться.

### Як це влаштовано

| Параметр | Значення |
|----------|----------|
| Endpoint | `https://api.github.com/gists` |
| Файл | `schedule.json` |
| Видимість | `public: false` (secret Gist) |
| Опис | `Family School Web - rozklad dzieci` |
| Заголовки | `Accept: application/vnd.github+json`, `User-Agent: fsc-web`, `Authorization: Bearer <token>` |

> ⚠️ **Важливо про безпеку.**
> - Токен зберігається **лише у `localStorage` вашого браузера** і надсилається
>   виключно на `api.github.com`. Ніякого сервера посередника немає.
> - Secret Gist не є приватним у повному сенсі: його можна прочитати, знаючи ID.
>   Синхронізуйте лише розклад дітей, не секретні дані.
> - Щоб відключити синхронізацію — **«Вимкнути синхронізацію»**. Локальні дані
>   залишаться на пристрої, але токен і Gist ID будуть очищені.
> - При помилці `Gist пошкоджено` (жовтий/червоний індикатор) дані зберігаються
>   локально, а пошкоджений Gist не перезаписується.

## Модель даних

Дані зберігаються двома ключами в `localStorage`:

| Ключ | Вміст |
|------|-------|
| `fsc.data.v1` | весь розклад (`{ version, children }`) |
| `fsc.settings.v1` | налаштування (`{ token, gistId }`) |

Структура розкладу:

```jsonc
{
  "version": 1,
  "children": [
    {
      "id": "m0abc123x4",              // uid: час у base36 + випадковий суфікс
      "name": "Софія",
      "class": "5-А",
      "color": "#4c8df6",             // колір вкладки
      "slots": [                       // рівно 10 записів: 8 уроків + 2 додаткові
        { "num": "1",  "label": "",            "start": "08:00", "end": "08:45" },
        { "num": "8",  "label": "",            "start": "14:30", "end": "15:15" },
        { "num": "★1", "label": "Гурток 1",   "start": "16:00", "end": "17:00" },
        { "num": "★2", "label": "Гурток 2",   "start": "17:15", "end": "18:15" }
      ],
      "days": {                        // 7 днів, у кожному масив із 10 комірок
        "mon": [ { "subject": "Математика", "room": "к. 203", "color": "#ffcf44" }, null, ... ],
        "tue": [ ... ], "wed": [ ... ], "thu": [ ... ],
        "fri": [ ... ], "sat": [ ... ], "sun": [ ... ]
      },
      "subjectColors": {               // колір прив'язаний до предмета (ключ — lowercase)
        "математика": { "name": "Математика", "color": "#ffcf44" }
      },
      "homework": [
        { "id": "…", "subject": "Математика", "text": "№ 1–24",
          "date": "2026-09-25", "done": false, "class": "5-А" }
      ],
      "exams": [
        { "id": "…", "subject": "Українська мова", "text": "Диктант",
          "date": "2026-10-02", "room": "к. 112" }
      ]
    }
  ]
}
```

**Дні тижня** зберігаються короткими ключами: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`.

**Типові часу за замовчуванням:** уроки 1–8 з 08:00 до 15:15 з перервами,
додаткові заняття — «Гурток 1» 16:00–17:00 і «Гурток 2» 17:15–18:15.
Усі часи редагуються.

**Стійкість до старих даних.** Під час завантаження виконуються
`normalizeSlots()`, `normalizeDay()` і `migrateSubjectColors()`: вони доповнюють
короткі масиви до 10 комірок і переносять колір, який раніше зберігався просто
в картці уроку, у `subjectColors`. Старі дані відкриваються без ручного втручання.

### Експорт та імпорт

- **Експорт** — кнопка внизу сторінки або меню ☰ → «Експорт JSON». Файл
  `family-schedule.json` містить увесь об'єкт `data`.
- **Імпорт** — «Імпорт JSON» → вибір файлу. Перевіряється наявність поля
  `children`; помилка формату показується alert-повідомленням. **Імпорт замінює**
  поточні дані повністю.

## Вимоги до браузерів

Сучасний браузер із підтримкою ES2020: **Chrome / Edge 88+**, **Firefox 90+**,
**Safari 15+**. Застосунок використовує `async/await`, `Map`/`Set`,
`<datalist>`, нативні поля `date` / `time` / `color`, `fetch` і HTML5 Drag & Drop.

Зовнішніх залежностей немає; єдине зовнішнє ресурс — шрифт Inter із Google Fonts
(застосунок працює й без нього — є `system-ui` у fallback).

| Можливість | Потрібне | Без цього |
|------------|----------|-----------|
| Розклад, домашка, контрольні | сучасний браузер | — |
| Збереження між сесіями | `localStorage` | дані зникають після закриття вкладки |
| Синхронізація | доступ до `api.github.com` | працює лише локально |
| Переміщення карток | миша (HTML5 DnD) | на touch-екранах недоступне |

## Розробка

Збірка, лінтери й пакетний менеджер **не потрібні** — це навмисна перевага проєкту.
Достатньо редагувати три файли й перезавантажити сторінку.

```bash
# запуск локально
python -m http.server 8000     # або: npx serve .

# швидка перевірка синтаксису
node --check app.js
```

**Точки розширення в `app.js`:**

| Ділянка | Призначення |
|---------|-------------|
| `DAYS`, `DAY_SHORT`, `DAY_FULL` | дні тижня та їхні підписи |
| `LESSON_COUNT`, `EXTRA_COUNT`, `TOTAL_ROWS` | кількість рядків розкладу |
| `SUBJECT_PALETTE`, `DEFAULT_SUBJECT_COLOR` | палітра кольорів предметів |
| `LS_DATA`, `LS_SETTINGS`, `GIST_FILENAME`, `GIST_API` | ключі сховища та Gist |
| `defaultLessonSlots()`, `defaultExtraSlots()` | часи дзвінків за замовчуванням |
| `normalizeSlots()`, `normalizeDay()`, `migrateSubjectColors()` | сумісність зі старими даними |
| `loadAll()` / `saveAll()` | читання та запис (localStorage + Gist) |
| `renderSchedule()` | побудова таблиці 7 × 10 і drag & drop |

Стилізація йде через CSS-змінні в `:root` (`--bg`, `--accent`, `--err` тощо),
тому тему можна перефарбувати в одному місці.

## Розгортання на GitHub Pages

Застосунок лежить у корені репозиторію — окремий workflow деплою не потрібен.

1. Відкрийте репозиторій → **Settings** → **Pages**.
2. У **Build and deployment** виберіть **Deploy from a branch**,
   branch `main`, каталог `/ (root)`.
3. Натисніть **Save**. Через хвилину застосунок буде доступний за адресою
   `https://<user>.github.io/FSC/`.

> Сайт працює по HTTPS — отже GitHub API приймає запити без проблем
> з mixed content.

## Відомі обмеження

Ці пункти актуальні й задокументовані, а не приховані:

| Проблема | Статус |
|----------|--------|
| Немає кнопки видалення для домашніх завдань і контрольних | лише редагування; обхід — експорт/імпорт JSON |
| Drag & drop не працює на touch-екранах | HTML5 DnR не підтримується на сенсорних пристроях; користуйтеся редактором уроку |
| `.github/workflows/validate.yaml` перевіряє HACS | залишився від попереднього Home Assistant-плагіну; для цього застосунку некорисний |
| `docs/images/` порожня | скріншоти видалено разом із HA-плагіном |
| Конфлікт при синхронізації | останній запис перезаписує попередній; захисту від merge конфліктів немає |
| Немає тестів | тести стосувалися видаленого HA-плагіну |

### Історія проєкту

Репозиторій еволюціонував: спочатку це був **Family School Cards** — набір
Lovelace-карток для Home Assistant (розклад, домашка, контрольні, інтеграція з
WebUntis), з `hacs.json`, власним тестовим набором і версіями до v1.5.0. У коміті
`1fd3c49` цей код було прибрано, а проєкт став **самостійним вебзастосунком** —
тим, який ви бачите зараз. Старі README і CHANGELOG описували той, попередній
продукт, тому вони не відновлені.
